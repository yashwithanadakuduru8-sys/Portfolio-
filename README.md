PORTFOLIO TECH STACK

This portfolio is built with a modern, performance-focused frontend architecture.

⚛ React 18

Component-based architecture for building a scalable and reusable user interface.

🔷 TypeScript

Adds type safety and better code structure for a more reliable and maintainable application.

🎨 Tailwind CSS

Utility-first styling system used to create a fully responsive, custom-designed interface.

🎬 Framer Motion

Powers advanced animations, including:

- Scroll-driven animations
- Sticky card interactions
- Character-by-character text reveals
- Entrance animations
- Dynamic transforms
- Smooth motion transitions

⚡ Vite

High-performance development environment and optimized production builds.

🎯 Lucide React

Modern, lightweight SVG icon system used throughout the interface.

🔤 Google Fonts — Kanit

Custom typography system with multiple font weights for the portfolio's bold visual identity.
